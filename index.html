    3Results

    The header row can be anywhere in the first 20 rows (title rows above it are fine); columns are matched by name (anything containing “table” and “column”). Without a header, columns are read by position: source, table, column, sample values, or table, column, samples if there are only three. Matching ignores case and surrounding spaces. Rows that already exist get the baseline markup filled in on the “Everything” tab.

    How it works

    Matching key
    Table name + column name. Case-insensitive, surrounding spaces ignored. Example values and markup are not part of the key.
    New table
    The table name doesn’t exist anywhere in the baseline.
    New column
    The table exists in the baseline but this column doesn’t.
    Removed
    In the baseline, missing from the new dictionary.
    Exists
    Already in the baseline. On the “Everything” tab these rows get the baseline markup copied in.
    Header row
    Found anywhere in the first 20 rows if it contains the words “table” and “column”. Without one, columns are read by position: source, table, column, samples (or table, column, samples if only three).
    Sources
    If the baseline holds several sources (Loopback, Omny…) and the new file names one, the baseline is narrowed to that source first.
    Google Sheets
    File → Download → Microsoft Excel (.xlsx) so every tab is included. A CSV export only holds the one tab that was open.
    Privacy
    Everything runs in the browser. Nothing is uploaded anywhere.
